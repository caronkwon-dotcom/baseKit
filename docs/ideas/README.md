# BaseKit Idea Backlog

이 폴더는 아직 구현이나 Architecture Decision으로 확정되지 않았지만, 향후 검토할 가치가 있는 아이디어를 대화에서 유실하지 않기 위해 관리한다.

## 상태 구분

- `IDEA`: 초기 아이디어, 타당성 검토 전
- `REVIEW`: 선택지와 영향범위 검토 중
- `PLANNED`: 사용자 승인 완료, WBS 반영 대기 또는 예정
- `MOVED`: ADR, Architecture 문서 또는 WBS로 이동
- `REJECTED`: 채택하지 않기로 결정

## 작성 기준

아이디어 문서는 최소한 다음을 포함한다.

```text
Status
배경과 문제
아이디어 요약
기대 효과
위험 및 영향범위
선행조건
결정이 필요한 사항
관련 문서
```

## 운영 원칙

- 아이디어 문서는 구현 완료를 의미하지 않는다.
- 승인 전에는 코드나 확정 ADR의 기준으로 사용하지 않는다.
- 중복 아이디어는 새 문서를 만들지 않고 기존 문서를 갱신한다.
- 구현이 결정되면 WBS와 완료 기준을 작성한다.
- Architecture 결정이 확정되면 `docs/decisions/` 또는 관련 문서로 이동한다.
- 특정 대화 원문을 그대로 저장하지 않고, 다른 작업자와 AI가 이해할 수 있는 독립 문서로 정리한다.
