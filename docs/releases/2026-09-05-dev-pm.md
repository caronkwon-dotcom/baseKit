# 2026-09-05 BaseKit 개발 반영 공지

## 배포 상태

`dev-pm` 개발 통합 및 검수 단계다. `main` 운영 기준 승격 전이므로 최종 배포 완료로 간주하지 않는다.

## 금일 반영 내용

- 시스템 공통 V1 테이블관리 화면과 Schema Catalog
- 7자리 테이블명 `B + 모듈 2자리 + 테이블 코드 4자리` 규약
- 마지막 4자리 고정 SQL Alias 규약
- 공통 감사 컬럼 `REG_DT`, `REG_BY`, `MOD_DT`, `MOD_BY`
- 사용·논리삭제 컬럼 `USE_YN`, `DEL_YN`
- 공통 Starter 임베드와 선택형 빈 Host 배포 Architecture
- Repository Markdown을 화면에서 확인하는 BaseKit 문서센터

## 검수 대상

1. 시스템관리 > 테이블관리에서 테이블·컬럼 정의와 공통 컬럼을 확인한다.
2. 개발자가이드 > BaseKit 문서센터에서 배포공지·확정규약·아이디어 분류를 확인한다.
3. 개발자가이드 > 화면 샘플에서 검색 Page Type 1·2를 실제로 검수한다.

## 다음 작업

시스템 공통 V1의 실제 DDL·Flyway Migration을 작성하고 사용자·회사·조직·역할·권한 Backend 계약을 연결한다.
