# 2026-09-12 Standard Design Module Foundation 개발 반영 공지

> 후속 feature branch에서 회사 LLM Backend 경유 연결 점검 기능을 개발 중이다. `dev-pm` 병합 전까지는 검수 완료로 간주하지 않는다.

## 배포 상태

`dev-pm` 반영 전 기능 브랜치 검수 단계다. PR 병합 전에는 최종 개발 통합으로 간주하지 않는다.

## 금일 작업

- Standard Design 화면 설계에서 Spring Backend를 경유하는 회사 LLM 연결 점검 기능 추가
- 회사 LLM Port/Adapter, 환경변수 설정과 비밀정보 비노출 오류 계약 추가
- Windows 실행 호환성을 위해 회사 LLM HTTP Client의 요청 Factory를 명시적으로 고정
- Product Module용 최소 `ApplicationModule` Manifest 계약 도입
- BaseKit 중앙 Program 목록을 Core 전용으로 한정
- Host Module Registry에서 Core Metadata와 Product Manifest 조립
- Standard Design 전용 Menu·Program·권한·Component Metadata 분리
- 중앙 공통 목록 수정 없이 Standard Design 전용 `SD_DESIGN_VALIDATE` Action 등록
- 프로젝트 관리, 고객 표준 관리, 화면 설계 Skeleton 추가
- Standard Design 등록 제거 상태의 BaseKit 단독 Production Build 검증

## 검수 대상

1. Top Menu의 `Standard Design` 진입
2. 프로젝트 관리, 고객 표준 관리, 화면 설계 세 화면의 MDI Tab 진입
3. 기존 시스템관리와 개발자가이드 메뉴 정상 동작
4. 문서센터에서 ADR-020과 금일 개발 반영 공지 확인
