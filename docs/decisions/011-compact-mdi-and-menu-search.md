# 011. Compact MDI and Menu Search

## 상태

Accepted

## 배경

업무 화면이 늘어나면 MDI Tab과 3Depth 메뉴의 긴 이름이 주요 작업 공간을 줄이고, Sidebar만으로 프로그램을 찾는 속도도 느려질 수 있다.

## 결정

### MDI Tab

- Tab 높이와 폰트를 Compact UI 기준으로 축소한다.
- Home은 텍스트 대신 작은 아이콘으로 고정한다.
- 프로그램명은 한 줄로 표시하고 너비를 넘으면 말줄임표로 줄인다. 전체 이름은 표준 Tooltip으로 확인한다.
- 열린 Tab을 자동으로 닫지 않는다.
- 화면에는 최대 10개를 보여주고 초과 Tab은 `… +N` 목록으로 이동한다. 현재 활성 Tab은 항상 표시 대상에 포함한다.
- `열린 Tab 목록`, `현재 외 닫기`, `전체 닫기`는 MDI 오른쪽 현재 위치를 유지하고 Compact 아이콘으로 표시한다.

### 메뉴 검색과 긴 이름

- Header에 메뉴 검색 아이콘을 두고 선택 시 Floating 검색창을 연다.
- 검색은 메뉴명과 `1Depth > 2Depth > 3Depth` 경로를 함께 대상으로 한다.
- 결과를 선택하면 Program을 열고 해당 1Depth와 활성 메뉴 Context를 자동 전환한다.
- 2·3Depth 메뉴명은 두 줄로 늘리지 않고 한 줄 말줄임표를 사용한다. 전체 이름은 Tooltip으로 확인한다.

## 영향

- 사용자가 많은 Program을 열어도 MDI 영역이 무제한으로 넓어지지 않는다.
- 메뉴 수가 늘어나도 Sidebar 탐색 외에 검색 진입 방식을 제공한다.
- 메뉴명 길이가 Shell 높이와 메뉴 행 높이를 변경하지 않는다.

## 후속 검토

- 키보드 단축키로 메뉴 검색 열기
- 최근 사용 메뉴와 즐겨찾기
- 사용자별 Tab 복원 정책
- 작은 화면에서 Floating 검색창과 Sidebar Overlay 충돌 검증
