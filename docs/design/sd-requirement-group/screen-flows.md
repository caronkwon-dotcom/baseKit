# 주요 화면 흐름

2026-10-06 · 디자인 흐름 / 제품 API 및 이동 경로 미확정

## F01 직접 구성

프로젝트 선택 → 그룹 목록 → 그룹 추가 또는 작성중 그룹 선택 → 기본정보 편집 → 요구사항에서 추가 → 전체 Requirement 검색 → 일부/현재 검색 결과 선택 → 누적 선택과 직접 추가 출처 확인 → 그룹 초안에 추가 → 그룹 저장 → 그룹 확정 확인 → 사용자 최종 확정.

추가 모달은 현재 그룹 포함 항목을 비활성화하고 다른 그룹 포함 항목을 허용한다. 검색 밖 선택은 별도 누적 선택 Grid에서 해제한다. 취소는 초안 미반영, 추가는 초안 반영, 저장은 영속 초안 저장, 확정은 다음 단계 사용 Gate 통과로 구분한다.

## F02 여러 독립 Analysis

Analysis에서 추가 → ANALYSIS-001의 기준/사유 확인 → REQ-002 선택 → ANALYSIS-003 이동 → REQ-010 선택 → 누적 선택 2건 및 각 실행 출처 확인 → 그룹 초안에 추가 → 직접 추가에서 REQ-007 추가 → 저장 → 확정.

어느 실행을 조회해도 자동 선택 0건이며 최신 실행이 이전 실행 선택을 대체하지 않는다. 기준 Requirement를 자동으로 그룹에 넣지 않는다. 필요하면 직접 추가에서 선택한다. Analysis 목록 정렬은 탐색 편의일 뿐 우선순위나 버전 순서를 뜻하지 않는다.

## F03 비교와 중복 출처

ANALYSIS-001에서 REQ-002 선택 → Analysis 비교 → 동일 REQ-002의 ANALYSIS-002 사유 읽기 → 다른 출처 선택 → 기존 출처/사유와 새 출처/사유 대조 → 기존 출처 유지 또는 명시적 변경 → 고유 REQUIREMENT_ID 1건 유지 → 누적 선택 검토.

선택한 요구사항에 대한 출처만 바꾸며 실행 결과 원문과 다른 basket 항목은 유지한다. 출처 변경 취소는 원래 선택 그대로다. 확정 그룹에 대한 출처 변경은 이 경로로 수행하지 않는다.

## F04 근거와 사람 판단

그룹 포함 Grid의 ANALYSIS-001 링크 → 실행 ID/시각·기준 Requirement·원본 추천 사유·사용자 포함 사유 읽기 → 닫기/실행 링크로 focus 복귀. 작성중/재검토 그룹의 사유 수정 → 공백 오류는 모달 내부 표시 → 유효 사유 초안 적용 → 저장. 수정은 원본 사유와 SOURCE_ANALYSIS_ID를 덮어쓰지 않는다.

## F05 확정 후 수정

확정 그룹(읽기 전용) → 구성 수정 → 작성중 전환 확인 → 성공 시 작성중 → 초안 편집 → 저장 → 재확정. 전환 실패는 확정 상태 유지. 재확정 전 최신 Context 사용은 차단하며 이미 만들어진 산출물은 조회 가능하게 유지한다.

## F06 Requirement 변경 / 폐기

Requirement 저장·폐기 → 해당 REQUIREMENT_ID의 포함 그룹 식별 → 재검토 필요 표시 → 기존 구성과 산출물 보존 → 변경 대상/사유 확인 → (구성 수정 또는 영향 없음 판단) → 각 변경 검토 완료 → 그룹 저장 → 현재 변경 기준 재검증 → 다시 확정.

폐기는 항목에 폐기 배지를 유지하고 명시적 제거를 제공한다. 폐기 항목 확정 허용 정책은 미결정이며 Prototype은 제거 전 확정 차단안이다. 변경 확인 중 또 변경되면 다시 검토하도록 하고 최종 확정 전에 서버가 현재 기준을 재검증해야 한다. 어떤 단계로도 자동 롤백하지 않는다.

## F07 Requirement 상세 → 그룹

저장된 Requirement 상세 → 연관정보 → 이 요구사항이 포함된 그룹 → 그룹명/상태/구성 수 확인 → 행별 요구사항 그룹에서 관리 → 해당 프로젝트의 대상 그룹 선택 상태로 이동. 예시 REQ-001은 2개 그룹에 포함된다. 업무관계와 그룹 포함을 혼동하지 않으며 상세에서 구성 편집하지 않는다.

## F08 이탈과 비동기 예외

미저장 초안 → 그룹/프로젝트/메뉴 이동 또는 MDI 닫기 → 계속 편집 / 저장 후 이동 / 변경 버리고 이동. 저장 실패·충돌은 이동하지 않고 입력 보존. 브라우저 닫기는 beforeunload 기본 안내에 맡긴다.

모달 누적 선택 → 닫기/Escape → 계속 편집 / 선택 버리고 닫기. 조회 실패·Empty/Loading은 기존 그룹·초안·다른 실행 선택을 보존한다. 프로젝트/그룹/실행 전환 후 늦은 응답은 해당 Context 검증 후 무시한다. 제품에서는 저장/확정 중 중복 요청을 막고 결과 불명은 상태 조회로 해소한 다음 재시도한다.
