# 미결정 사항 및 제안

2026-10-06 · 아래 제안은 승인된 API/DB/Architecture 결정이 아니다. 이번 설계의 필수 의미는 작업지시가 우선한다.

| ID | 결정 필요 | DESIGN 제안 / 현 Prototype | 결정 담당 / 구현 영향 |
|---|---|---|---|
| D01 | 독립 관련 Requirement Analysis 저장·조회 계약 | 실행별 불변 ID/기준 Requirement/추천 항목/원본 사유 유지. 기존 Program 분석 reanalyze 계약을 그대로 사용하지 않음 | SD·PM, 신규 업무 계약 선행 |
| D02 | 동일 Requirement의 근거 1개/여러 개, 사후 출처 변경 | 구성 항목은 고유 Requirement 1건, basket에서 출처 1개 명시 결정. 다중 근거·저장 후 교체는 미지원 | SD·사용자, 데이터 cardinality 결정 |
| D03 | 저장 단위/미저장/신규 ID | 기본정보+구성 전체 초안 저장, 확정 별도. Prototype 새 그룹은 메모리 ID 예시 | SD, 원자성·동시성·임시 ID 정책 |
| D04 | 변경 감지 범위와 검토 기준 | 수정/폐기 시 관련 그룹 재검토, ID 참조 유지. 비교 기준/판단 기록 보존. 작성중 그룹도 상태 전환하는 안 | SD·PM, 이벤트/조회 재검증, 검토 이력 정책 |
| D05 | 폐기/삭제/접근 변경 항목의 확정 정책 | 자동 제거하지 않고 폐기 표시, 명시적 제거 전 확정 차단 | SD·사용자, 과거 산출물/감사 보존 |
| D06 | 재확정과 후속 산출물 최신성 표시 | 기존 산출물 유지, 최신 Context 입력 Gate만 재오픈. 과거 분석이 사용한 구성 기준 표시 | SD·PM, 단계 롤백 금지, 최신성 계약 |
| D07 | AI 활용 배지의 의미 | 현재 포함 항목 중 Analysis 출처 존재 기준. 이력은 별도 | SD·사용자, 목록 계산 기준 |
| D08 | 명칭/중복/길이/포함 한도/허용 Requirement 상태/권한 | 그룹명 필수, 포함 1건 이상 외에는 임의 제약 확정 안 함 | SD·PM, 서버 validation/Action 계약 |
| D09 | 넓은 모달 및 공통 focus 지원 | FormModal 우선, 좁은 화면 한 열. 1080px는 Prototype 표현. 초기 focus/trap/복귀 필요 | COMMON·DESIGN, 공통 확장 필요 시 별도 요청 |
| D10 | 그룹 관리·별도 Analysis·후속 그룹 분석의 라우트/Program ID | Requirement 상세에서 프로젝트+그룹 ID를 전달하여 대상 선택. 제품 신규 메뉴는 구현하지 않음 | SD·COMMON, MDI/Manifest/권한 연결 |
| D11 | 근거 삭제·보존기간·원본 사유 참조 | 원문 전체 복제 대신 실행 근거 참조. 조회 불가를 별도 표시 | SD·PM, 감사/보존정책 확정 |

제품 구현 착수 전 D01~D06/D08/D10은 업무 계약으로 확정해야 한다. D09는 기존 공통 지원 여부 확인 후 최소 요청으로 분리한다. UI 설계 검토는 현 Prototype으로 진행 가능하나 제품 기능 완료로 표시하지 않는다. 이 문서의 결정 담당 표기는 인계 제안이며 외부 팀에 메시지를 발송한 기록이 아니다.
