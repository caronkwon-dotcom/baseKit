설계 의견

원문: 고객 주문을 접수하고 담당자 승인 후 주문 상태를 변경한다.

저장된 요구사항 본문과 선택된 요구사항의 개별 의견·종합 의견만 전송합니다. 첨부 본문·OCR·변경이력은 포함하지 않습니다.

실제 제품에서는 서버를 경유해 회사 LLM을 호출합니다. 진행률 계약이 없어 퍼센트는 표시하지 않습니다.

요구사항 또는 설계 의견이 변경되었습니다. 현재 분석 결과는 이전 입력 기준입니다. 다시 분석한 후 확정할 수 있습니다.

이전 결과는 보존되어 읽을 수 있습니다. 후보 선택·편집·확정·생성은 차단됩니다.

출처 요구사항→LLM 분석→업무구조 · 프로세스 · Layout→프로그램 후보→선택 · 확정 · 생성

분석 요약

주문 접수·승인 업무와 승인 이력 조회를 분리하고 요구사항 출처를 각 후보에 연결합니다.

업무구조와 프로세스·Layout은 설계 추천이며 사용자 확정 전에는 생성되지 않습니다.
